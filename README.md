# U2-ejercicio17

### Ejercicio: La Estación de Carga para Vehículos Eléctricos

**Objetivo:** Simular la comunicación entre objetos en Java mediante el intercambio de mensajes entre un vehículo eléctrico y un surtidor, permitiendo transferir energía, controlar el nivel de batería y detener automáticamente la carga al alcanzar el 100%.

Desarrollo de un sistema de carga eléctrica utilizando las clases `VehiculoElectrico`, `SurtidorElectrico` y `Main`, aplicando encapsulamiento, métodos y comunicación entre objetos.
